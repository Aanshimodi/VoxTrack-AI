# 🎙️ VoxTrack AI – Voice Expense & Task Tracker

VoxTrack AI is a voice-powered productivity application that helps users manage their daily expenses and tasks using simple voice commands. It makes tracking activities easier, faster, and more convenient.

## 🚀 Features

- **Voice Commands:** Add expenses and tasks using your voice.
- **Expense Tracking:** Record expenses with amount and category.
- **Task Management:** Create and manage daily tasks.
- **Voice Interaction:** Interact with the application through speech.
- **Dashboard:** View expenses and tasks in one place.
- **Data Persistence:** Keep recorded information available after refreshing the application.
- **User-Friendly Interface:** Simple and interactive dashboard.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript / TypeScript
- Vite
- Browser Speech Recognition
- Speech Synthesis API

## 💡 Example Voice Commands

- "I spent 250 rupees on lunch."
- "Add a task to complete my assignment."
- "I spent 100 rupees on shopping."

## 🎯 Objective

The objective of VoxTrack AI is to simplify expense tracking and task management by using voice-based interaction, making everyday productivity more accessible and efficient.
